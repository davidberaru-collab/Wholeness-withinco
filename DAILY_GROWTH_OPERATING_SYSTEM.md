# Wholeness Within Co. — Daily Growth Operating System

Date created: May 13, 2026

This document is the daily execution framework for operating Wholeness Within Co. like a premium Shopify growth agency.

## Operating constraints
- Never edit live theme directly.
- Ship through Git branches + PRs only.
- Use unpublished preview theme for every major release.
- Do not modify checkout/payment/tax/shipping/inventory/customer data without approval.
- Keep all credentials in environment variables only.

---

## 1) PRIORITY ACTIONS (highest ROI first)

### P0: Unblock engineering execution (Day 0)
1. Pull current published Shopify theme into this repo (`shopify theme pull`).
2. Establish branch naming and PR template with preview URL + rollback notes.
3. Create a baseline analytics snapshot (CVR, AOV, RPS, ATC, email opt-in, LCP).

### P1: Immediate conversion uplift (first 7 days after theme import)

2. PDP trust stack near ATC: guarantee, shipping window, satisfaction messaging.
3. Sticky mobile ATC + objection-handling FAQ on PDP.
4. Email capture section + lead magnet routing page.

### P2: Growth compounding (days 8–30)
1. SEO content engine + collection/PDP metadata optimization.
2. Bundle/upsell merchandising modules.
3. Klaviyo lifecycle flow stack (welcome, abandon cart, win-back, VIP).

## 3) CONVERSION FIXES

### Homepage fixes
- Place single dominant CTA in hero: "Start Your Skin Ritual"
- Add "why tallow" credibility block with science-backed plain language
- Insert social proof rail (reviews + before/after + UGC stills)
- Add audience-path cards: Sensitive Skin / Mother’s Routine / Holistic Wellness

### PDP fixes
- Put benefits-first bullets above long description
- Add skin-type selector and "best for" badges
- Add ingredient transparency accordion with sourcing details
- Move testimonials directly under purchase module
- Add urgency without hype: "Small-batch made weekly"

### Cart fixes (non-checkout edits)
- Progress bar to free-shipping threshold
- In-cart complementary suggestion
- Trust microcopy: returns/guarantee + response-time assurance
